# Habit Tracker Backend

Backend API for the Habit Tracker app.

## Setup

1. Install dependencies:
   ```bash
   npm install
   ```

2. Create a `.env` file (see `.env.example`):
   ```
   PORT=5000
   MONGODB_URI=your_mongodb_connection_string
   JWT_SECRET=your_jwt_secret
   ```

3. Run the server:
   ```bash
   npm start
   ```
